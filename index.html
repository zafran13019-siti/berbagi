FAQ

Penjelasan singkat agar pengunjung mengerti fungsi halaman dan cara kerja promonya.

Apakah halaman ini bisa langsung diunggah ke GitHub?

Bisa. Simpan file ini sebagai `index.html`, unggah ke repository GitHub, lalu aktifkan GitHub Pages di pengaturan repository.

Apakah data peserta masuk ke database?

Belum. Versi ini hanya demo front-end. Untuk data nyata, sambungkan ke layanan formulir atau backend resmi.

Apakah bisa melihat siapa yang menyimpan nomor kita?

Tidak. Hal itu tidak tersedia secara sah dari halaman HTML statis dan tidak disediakan di template ini demi privasi.

Bagaimana cara mengganti nomor admin?

Edit konfigurasi JavaScript pada bagian `siteConfig` di bagian bawah kode untuk mengganti nama kontak, nomor WhatsApp, dan tautan chat.
